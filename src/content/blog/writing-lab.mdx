## 让代码更好读

代码块带有文件名、行号、复制按钮。下面的示例还演示了高亮行：

```ts title="hello.ts" {2-4}
type Note = { title: string; published: boolean };
const notes: Note[] = [
  { title: '一个新的想法', published: true },
];
const published = notes.filter(note => note.published);
console.log(published);
```

差异可以用 `diff` 代码块表达：

```diff title="记录一次小改进"
- const result = items;
+ const result = items.filter(item => item.published);
```

## 折叠补充说明

<details>
<summary>所有文件都能直接在线预览吗？</summary>
<div>不是。下载可以链接任意附件，但在线预览依赖浏览器或专门组件。PDF 在桌面浏览器里通常可以预览；DOCX、PPTX、XLSX 建议提供下载，或先转换为 PDF。视频和音频也取决于浏览器支持的编码。</div>
</details>

<Callout type="warning" title="公开站点的边界">
放进 public 目录并部署的文件是公开资源，没有登录鉴权。不要上传身份证明、密钥或其他不希望公开的材料。MDX 可以执行代码，只提交你自己信任的内容。
</Callout>
