> 这是一篇站点欢迎示例。你可以直接修改本文，写下自己的第一篇文章。

## 为什么留下这些文字

有些问题，在动手实现之后才真正理解；有些经验，在写下来之后才真正属于自己。

这个空间不追求一开始就填满内容。它更像一个工作台：先把正在思考的东西放上来，再慢慢打磨。

## 这里可以放些什么

**技术笔记**记录理解的过程，而不只是一个结论。**实践记录**留下选择、取舍和踩过的坑。**资源分享**让源码、文档和数据有一个清楚的入口。

不需要把每篇文章都写成教程。一个小问题，一段关键的代码，也可以是很好的开始。

## 从第一篇文章开始

在项目根目录运行下面的命令，会创建一篇默认不发布的草稿：

```bash title="新建文章"
npm run new -- my-first-post
```

打开 `src/content/blog/my-first-post.mdx`，修改标题和正文。写好之后，把 `draft: true` 改成 `draft: false`，提交到 GitHub。

博客的外观可以慢慢调整，真正让它变得独特的，是你放进来的内容。
