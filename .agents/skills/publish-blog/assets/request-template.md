# 给 Agent 的发布请求

最简写法：

> 按 xiaoyumuxi/Blog 仓库的 AGENTS.md 和 publish-blog Skill，把下面来源中的「指定章节」发布成文章。保留原文、高亮、折叠和元数据，不改固定栏目。

## 可选补充

```text
来源：Notion 链接 / 粘贴正文 / 上传文件
范围：整篇 / 某个标题下面的内容（到哪个标题结束）
动作：预览 / 发布 / 更新已有文章 / 删除
标题：沿用原题 / 自定义
slug：自动拟定；更新时填原 slug
标签：保留原标签 / 指定 tags
内容处理：原样迁移 / 只改排版 / 允许润色（不改变事实）
强调：保留红色、其他颜色、粗体、代码、折叠
附件：哪些一起公开；哪些必须排除
日期：立即发布（UTC+8）/ 明确日期
固定栏目：保持不变（默认）/ 明确的新顺序
```

不填写的项目按 Skill 默认处理，不必每次填完整表。没有「发布」指令时不推送私人内容。明确未来日期但没有调度触发时，需要先确认如何触发静态构建。
