# 源内容 → MDX 保真规则

## 源材料与边界

Notion 源内容必须通过已授权连接读取，处理完整分页和嵌套块；用户提供的「章节范围」决定公开边界。不要把页面属性、父级面包屑、作者实名、工作区名、内部 URL、访问令牌一起导出。公开出处可按用户要求保留；私人源地址只用于本次读取，不进入 frontmatter、页面、注释或提交消息。

用户要求原样发布时，允许转换标记语法和改善排版，不允许摘要代替全文、删纠偏句、编造经历、添加未经核实的数据。需要纠错时标出建议，让用户决定是否改正文。附带脚本、源 MDX 的 imports、动态表达式、事件处理器均先审查，不直接执行。

## 结构映射

| 来源 | 目标 | 检查 |
| --- | --- | --- |
| 页面标题 | frontmatter `title`，模板生成唯一 H1 | 正文不再重复同一个 H1 |
| 章节 / 小节 | `##` / `###` | 目录与实际锚点可跳转，中文锚点取生成结果而非猜测 |
| 问答折叠 | `<details><summary>…</summary>…</details>` | 外层题组、内层问题分别计数，嵌套完整 |
| 加粗 / 斜体 / 删除线 | Markdown 或显式 HTML | 不跨 JSX 标签配对 `**` |
| 文字颜色 / 背景高亮 | 安全 class / 本站颜色组件 | 不以统一主题为由丢掉源颜色语义；亮暗可辨 |
| 代码 | 指定语言围栏 / 行内 code | 字符、空格、`< > { }` 等不被误执行 |
| 表格 / 列表 / 引用 / 脚注 | 对应 Markdown / 安全 HTML | 行列与嵌套数量完整 |
| 图片 / 图集 | 授权下载的本地资源或稳定公开 URL | alt、图注、比例和放大可用，无签名过期链接 |
| 数学 / Mermaid | KaTeX / 已有 Mermaid 处理 | 真实构建中验证，不只在编辑器看源码 |
| 文件 | `public/downloads/` 与 `DownloadCard` | 原文件类型正确、路径可访问、隐私已检查 |
| PDF | `PDFViewer` + 下载回退 | 预览不支持时仍可下载 |
| 多列布局 | 线性阅读顺序或明确的布局组件 | 不把相邻列无关内容混入指定章节 |

新稿不使用某组件时不要只为展示能力强行插入。本站 `InterviewGuide` 目前包含该八股文章的固定章节，不能直接复制到无关文章；需要通用指南时先参数化再测试。

## 红色重点：已知编译陷阱

Notion 可能将一句话拆成多个相邻片段，并把加粗符号放在空格两侧。以下模式不可靠：

```mdx
<span className="notion-red">**注意这里 **</span><span className="notion-red">**`i++`**</span>
```

Markdown 的粗体分隔符可能跨越 JSX 边界配对，typecheck 通过也可能在 build 时失败。使用明确闭合的节点；不要将所有标签简单替换成空串：

```mdx
<strong className="notion-red">注意：<code>i++</code> 不保证复合操作原子性。</strong>
```

包含 JSX 特殊字符时，使用字符实体或可信字面量，不把源文本拼成可执行表达式：

```mdx
<strong className="notion-red">占位符 <code>&#36;&#123;value&#125;</code> 与 <code>&lt;tag&gt;</code></strong>
```

普通加粗仍可用 `**重点**`。同一强调句合并相邻同色片段时，保留空格、代码与标点，并记录为什么片段数减少。检查的是语义与实际输出，不是硬套以前文章的数字。新增其他颜色先检查现有样式，不用玫红代替所有源颜色。

## 元数据与固定栏目

frontmatter `tags` 是文章内容描述。例如：

```yaml
tags: [八股, 后端, Java, MySQL, Redis, AI]
```

即使固定栏只显示几个主题，这些 tags 也全部保留。发布稿件不能改 `src/data/article-filters.json`；明确改栏目的任务才改它。`label` 与匹配 `tag` 可以不同，但不自动建立模糊同义词规则。

当前 schema 支持 `title / description / date / tags / draft / featured / sample / art`，每次以实际文件为准。更新保留旧字段，特别是 slug 和日期；不要自创 `author`、`category`、`source` 字段后假装模板会读。

## 来源清单（仅临时保存）

```text
范围：指定章节
章节标题：逐项记录
题组：N；具体问题：M（分别记录）
红色强调：N 段；其他文字色/背景色：逐类记录
代码 / 表格 / 图片 / 附件：逐类记录
关键文字：挑选开头、中间、结尾及易丢失重点
未支持项：必须列出；无则写无
```

不得把含私人数据的原始材料或上述清单直接提交到公开仓库。可以在回执中给出无敏感信息的总数和差异说明。
